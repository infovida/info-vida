# InfoVida icons

Selected Lucide icons from lucide-react 0.487.0, the same package used by the
Figma Make reference. See LICENSE-lucide for ISC/MIT attribution and contributors.
SVG source and 96×96 transparent PNG exports are committed here. Native Image
applies tintColor and scales them to 16–40 logical points. Active artwork has
stroke width 2.5; regular artwork uses 2. No font or SVG runtime is required.

To regenerate on Ubuntu with librsvg-2 and libcairo installed:

```bash
python3 scripts/render-icons.py
```

The app does not run this script at install or startup.
