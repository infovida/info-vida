# Ilustrações das notícias fictícias

Ilustrações vetoriais criadas em código para esta demonstração do InfoVida.
Não são fotos de eventos reais nem material atribuído a instituições externas.
Fontes SVG e PNGs locais 800×450 (16:9), na paleta do Figma Make.

Regerar no Ubuntu com librsvg/cairo: `python3 scripts/render-news-covers.py`.
O aplicativo não executa o script e não acessa imagens externas.
